About this project

A machine-learning web app that predicts solar power generation from weather conditions.

How it works

You enter temperature, humidity, solar irradiation and wind speed. A Random Forest regression model (scikit-learn) trained on dataset.csv predicts power in kW. Daily energy is power × peak sun hours; savings use your tariff; CO₂ uses an emission factor of 0.82 kg/kWh.

Features

Real-time prediction · interactive dashboard · prediction history · daily/weekly/monthly analytics · actual vs predicted chart · model accuracy · CSV report · low generation and high temperature alerts · best generation time · recommendations.

Tech stack

HTML, CSS, JavaScript · Python · Flask · scikit-learn · pandas

Run it

pip install -r requirements.txt
python train.py
python app.py → open http://127.0.0.1:5000
